# RIZO / demos de servicios tecnológicos

Una SL ficticia de diseño y desarrollo de productos digitales para grandes organizaciones. Este ejercicio reúne tres webs independientes en rutas separadas: una campaña pública, un sistema de operaciones y una experiencia de feria. Identidad, casos, recinto, resultados y testimonios son conceptos simulados; no representan clientes ni resultados reales.

La demo se materializa desde este directorio en `.cache/demo-rizo/` con `npm run rizo:prepare`. Requiere las dependencias locales del consumidor existente en `.cache/demo-umbral-espacios`; el preparador las copia para aislar `node_modules` y `.next`. Vistas: `/campaign`, `/system` y `/forum`.
