# Construir con Trama

Detecta el proyecto desde su directorio de trabajo: ejecuta `node <directorio-de-esta-skill>/scripts/context.mjs --cwd <proyecto>`. El resultado identifica paquete, versión, imports, conocimiento y límites. No uses `npx trama-ui@latest` para consultar una versión instalada ni actualices dependencias para hacer encajar un ejemplo. Si hay código copiado, revisa `.kit.json` y las adaptaciones locales.

Abre el `knowledge/index.json` de esa instalación y después solo la receta, guía y piezas necesarias. La selección piloto es parcial: una pieza ausente del índice puede existir en el paquete; consulta su `CATALOG.md`, exports y declaraciones antes de concluir que falta. Si la instalación antigua no tiene knowledge, usa sus declaraciones y catálogo; no le apliques fichas de otra versión.

Concreta público, contenido, páginas, acción principal y alcance de integración usando el encargo. Compón con secciones cuando encajen y baja a piezas para resolver lo específico. Pasa copy propio explícito y `""` para textos opcionales que se oculten. Las props `playgroundProps` son controles del visor: `api.declaration` y las declaraciones de los exports públicos gobiernan objetos, callbacks y composición. No importes demos, catálogo o rutas internas del paquete. Deriva tipos anidados con `ComponentProps` cuando no tengan export propio.

Aplica la guía elegida mediante `GuideFrame`, tokens y clases `ui-g-*`; la variante se pasa a cada pieza que la admita. Usa CSS público una vez. En Next consulta sus docs locales antes de crear rutas; para `trama-ui/fonts`, usa la configuración de fuentes comprobada que indique el contexto. No copies `/img/...` de una demo: declara recursos propios y sus licencias.

Incluye una imagen solo si ayuda al contenido o a la dirección elegida. Para fotos, ilustraciones o texturas raster originales, usa la herramienta de generación de imágenes si el cliente actual la ofrece (por ejemplo, Codex imagegen); es opcional y no asumas que está disponible. Si no lo está, usa recursos aportados o con licencia adecuada, o resuelve con SVG/CSS/componentes. Prefiere código para iconos, logotipos, diagramas y patrones simples. Revisa la imagen generada, el recorte y su comportamiento responsive; añade texto alternativo útil o alt vacío si es decorativa. No presentes imágenes generadas de personal, instalaciones o resultados como hechos reales.

Completa los estados relevantes del recorrido y declara lo que se simula. En reservas piloto: estado por instancia/localStorage, ocupación ficticia y `onBooked` posterior a confirmación; no es una transacción de agenda. La query se adapta en la página, no la lee `BookingFlow`. No prometas correo, pagos, identidad, persistencia remota o disponibilidad real sin integración probada.

Verifica tipos/build y el recorrido en navegador, incluyendo móvil, teclado/foco, errores, vacío, confirmación y movimiento reducido según impacto. Inspecciona también todos los textos visibles susceptibles de solaparse, incluidos metadatos en `span`/`div`, texto vertical/rotado y etiquetas superpuestas a imágenes, no solo titulares y controles. Acepta capas y colisiones tipográficas si la composición las usa deliberadamente y el texto sigue claro; trata como fallo cualquier texto tapado, recortado o visualmente mezclado que cueste leer, y cualquier capa que capture el clic destinado a un control. Comprueba tamaño y contraste de microtexto decorativo al tamaño real. No te limites a una captura móvil y otra de escritorio: incluye los anchos de referencia y los breakpoints CSS que cambien la composición, probando cada breakpoint por ambos lados, más los anchos intermedios cercanos a sus mínimos de columna. Si hay captura de escritorio, comprueba su resolución y prueba el ancho CSS completo: «1080p» suele ser 1920 px de ancho. En este repo ejecuta `npm run qa:visual-text -- <url> --widths ...` para señalar colisiones, clipping, texto de bloques vecinos demasiado próximos y texto que rebasa el borde de su caja flex/grid; revisa visualmente marcas/índices contra separadores y kickers, además de cursivas y palabras que desbordan columnas. El detector produce candidatos: titulares de cartel, interlineado compacto y capas deliberadas también generan avisos. La intención estética no basta para darlo por bueno si reduce legibilidad; ajusta jerarquía, contraste, espaciado o encuadre. Una captura o compilación no certifica el flujo. Entrega cambios, evidencia y límites; si el usuario pidió construir, continúa hasta resolver los criterios autorizados sin rondas rutinarias de aprobación. Publicar o desplegar exige autorización propia.
