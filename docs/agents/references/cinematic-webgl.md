# Atlas de firmas cinemáticas de Trama

Uso: guía de selección y traducción para demos inspiradas en una web con escena, WebGL, WebGPU o coreografía de scroll. No es una galería de templates. Para cada caso, conserva mecanismo y sensación; crea arte, marca, texto y tema propios. El código de las rutas fuente solo está disponible cuando se trabaja en el repo de Trama.

## Caso de regresión: Igloo → POLARIS (octubre de 2026)

La primera POLARIS se documentó como inspirada en Igloo, pero implementó una fotografía con desplazamiento UV, ruido, aberración cromática y una capa de “escarcha”. Era un efecto de imagen en WebGL 1; no tenía malla 3D, transformación de objeto, campo de partículas, cambios de escena ni coreografía. La investigación había observado precisamente geometría procedural, Three, instancias, scroll, clic y posprocesado. Por eso esta versión es una **falla de fidelidad cinemática**, aunque copy, accesibilidad, interacción editorial y validación funcional estuvieran completos. No citarla como ejemplo exitoso ni usar su shader de foto como fallback de una escena 3D.

En la corrección se debe ver en la misma prueba: (1) un objeto/espacio 3D propio; (2) movimiento de cámara u objeto activado por los gestos estudiados; (3) más de un estado de escena o una progresión de forma; (4) capas de profundidad/partículas/atmósfera equivalentes en intención, no necesariamente en número; (5) transición visual sincronizada con los estados; (6) texto legible fuera del canvas. Arte, datos, palabras y modelo son originales.

## Cómo implementar sin copiar

1. Escribe una **firma mínima comprobable**: por ejemplo «al avanzar la rueda, la geometría crece y abre una cámara interior; el puntero altera el flujo de partículas; los capítulos cambian mediante aberración y velo de escarcha».
2. Prototipa el medio y la coreografía en una sola escena antes del sitio. Si la referencia usa Three y el objeto/profundidad definen la experiencia, implementa Three/R3F; no reemplaces la escena por una foto más un filtro.
3. Traduce significado, no malla: cambia el objeto por otro con igual función narrativa (p. ej. una estructura científica transformable), genera materiales/geometría propios y cambia todos los activos/textos/datos.
4. Graba referencia y demo con el mismo viewport, recorrido, gestos y momentos (`cine:capture`, `cine:analyze`, `cine:compare`/`cine:vuelta`). Compara composición, gesto, coreografía, profundidad, ritmo y acabado; mide incertidumbre de la referencia viva antes de fijar objetivo.
5. Si una limitación de coste, CSP, móvil o API fuerza una diferencia, regístrala y da una alternativa de menor fidelidad como trade-off explícito; no la presentes como reproducción equivalente.

## No extraer una sola plantilla

Las referencias anteriores no comparten estructura. Lusion y Meer Mohsin usan emblema/objeto y scroll, pero el primero trabaja espacio/cámara y el segundo una coreografía gráfica roja y transición de papel. Quilate/Ánima fijan el objeto junto a capítulos y una web posterior; Plain Sight convierte glifos en topografía; Hublot usa punto de vista; Chartogne usa grabado. Selecciona el concepto correspondiente y consulta el código solo de esa referencia. La plantilla común solo sale de una síntesis de al menos tres webs y describe únicamente rasgos repetidos.
